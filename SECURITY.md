# Security and privacy boundaries

This public artifact was authored separately from the private source. Do not add production code, environment files, real contact details, customer documents, live-system account information, or source history to it.

## Demo behavior

- Records and financial figures are invented.
- Contact addresses use the reserved `example.com` domain.
- Demo edits are stored only in the current browser.
- Reset clears the demo's state, not other browser data.
- Payments, quote preparation, and delivery are simulations.
- There are no payment, messaging, email, authentication, or database calls.
- No personal data needs to be entered. Do not use this demo for actual customer work.

## Before publishing future changes

Review new content for private names, phone numbers, internal identifiers, production domains, secrets, uploaded documents, and accidental inclusion of the private repository. A simple token scan is useful but is not a guarantee that a file is safe to publish.

If an actual credential is ever published, revoke and replace it. Deleting it from the latest file does not remove copies from repository history or other people's downloads.

## Source access

The private application is separate. Public access to this showcase does not provide access to its source or data. Anyone can copy public files from this repository; source protection comes from keeping the underlying application private, not from download-blocking scripts.
